# Desk Pick — установщики

Desk Pick — удалённый доступ к рабочему столу по одноразовому коду. Один аккаунт с VPN Pick.

Здесь лежат только готовые установщики. Скачать последнюю версию — во вкладке
[Releases](https://github.com/Artiishock/deskpick-releases/releases/latest).

Проверить файл (PowerShell): `Get-FileHash .\deskpick-setup-<версия>.exe` — хэш
должен совпасть с SHA-256 в описании релиза.
